# 🛒 Walmart Sales Forecasting (Time Series + ML)

## 📌 Overview

This project predicts Walmart weekly sales using multiple time series and machine learning models.

## 🎯 Objective

To compare different models and identify the best approach for forecasting retail sales.

## 🧠 Models Used

* Prophet
* SARIMAX
* Random Forest
* XGBoost

## ⚙️ Steps Performed

* Data Cleaning & Preprocessing
* Feature Engineering
* Time Series Analysis
* Model Building
* Model Comparison

## 📊 Results

* Compared 4 models using RMSE & MAE
* XGBoost / SARIMAX performed best (based on results)

## 📈 Key Insights

* Sales increase during holidays
* Seasonal patterns observed
* External factors impact sales

## 🚀 Future Improvements

* Hyperparameter tuning
* Deep learning (LSTM)
* Real-time prediction system
